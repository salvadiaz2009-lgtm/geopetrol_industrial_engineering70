# INSTRUCCIONES DE DESARROLLO FULL-STACK: GEOPETROL S.A.

## 1. OBJETIVO DEL PROYECTO
Implementar la funcionalidad de backend y la interactividad de JavaScript para los formularios de cotización y contacto en la landing page industrial de **GEOPETROL S.A.** (diseñada bajo el estilo *Industrial Brutalism*). Actualmente la página es puramente estática (`code.html`).

---

## 2. FUNCIONALIDAD DE LOS BOTONES Y NAVEGACIÓN
- **Botones de "Solicitar Cotización" (Header y Hero):** Deben hacer un scroll suave (*smooth scroll*) directo hacia la sección de "COTIZACIÓN RÁPIDA" (`#cotizacion`) para que el usuario interactúe de inmediato con el formulario.
- **Botones de "Ver Detalle" en Portafolio Técnico:** Deben abrir un modal desplegable (o expandir una tarjeta colapsable) que detalle las especificaciones técnicas bajo normativa API de cada servicio.

---

## 3. LÓGICA DE ENVÍO DE FORMULARIOS (COTIZACIÓN RÁPIDA Y CONTACTO)
Se debe programar un script en JavaScript (`main.js` o embebido) que intercepte el evento `submit` de los formularios mediante la API `fetch` para evitar recargar la página.

### Datos a capturar del Formulario de Cotización Rápida:
1. `empresa` (Texto)
2. `tipo_de_proyecto` (Selección: Construcción, Mantenimiento, Personal Técnico, Alquiler de equipo)
3. `urgencia` (Selección: Inmediata < 24h, Normal 3-5 días, Planificación 1 mes+)

### Datos a capturar del Formulario de Contacto Industrial:
1. `nombre_completo` (Texto)
2. `empresa` (Texto)
3. `correo_corporativo` (Email)
4. `servicio_de_interes` (Selección)
5. `detalles_tecnicos` (Textarea)

---

## 4. ARQUITECTURA DE BACKEND Y ENVÍO DE PROPUESTAS/CORREOS
Antigravity debe configurar una API (por ejemplo, con Node.js / Express o Serverless Functions) que procese los datos anteriores y ejecute el siguiente flujo de comunicación:

### A. Notificación Interna para la Empresa (Tú / Equipo Comercial)
- **Destinatario:** `info@geopetrol.co.ve`
- **Servicio sugerido:** Resend, SendGrid o Nodemailer configurado con SMTP corporativo.
- **Formato del Correo:** Un mensaje estructurado en HTML con los datos exactos que ingresó el cliente, destacando el nivel de urgencia en rojo (`#D42728`) si es "Inmediata".

### B. Notificación Automática de Recepción para el Comprador (Cliente)
- **Destinatario:** El correo corporativo que el cliente colocó en el formulario.
- **Contenido del Correo:** Un mensaje automático de confirmación:
  > *"Estimado equipo de [Nombre de la Empresa del Cliente], hemos recibido su requerimiento técnico con código #GP-2026-X. Un ingeniero consultor de GEOPETROL se pondrá en contacto con ustedes en menos de 2 horas."*

---

## 5. EXPERIENCIA DE USUARIO (UX) DURANTE EL ENVÍO
- Al hacer clic en enviar, el botón debe mostrar un estado de carga (ej. *"Procesando Requerimiento..."* y deshabilitarse temporalmente).
- Al completarse con éxito, el formulario debe limpiarse y mostrar una alerta visual limpia o un mensaje emergente de éxito adaptado al diseño *Industrial Brutalism* (bordes de 2x sólidos, fondo blanco o contenedor de contraste).
